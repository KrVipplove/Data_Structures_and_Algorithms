HTML - Entities

HTML entities are special codes used to display reserved or special characters in HTML.

Because some characters have special meaning in HTML, you can’t type them directly.

Example:

  • Tag for writing paragraph in HTML - <p></p>
  • For displaying entities itself is to replace '&' with '&amp;'

Example of entities:

  • (&lt;) for (<)
  • (&gt;) for (>)
  • (&amp;) for (&)
  • (&copy;) for (©)
  • (&nbsp;) for non-breaking space (space that cannot break into a new line)

pre Tag

<pre> displays text exactly as you write it in your HTML.

Input:

<pre>
        I  love      you

        I    miss

        you so 


        much
</pre>

Output:

        I  love      you

        I    miss

        you so


        much

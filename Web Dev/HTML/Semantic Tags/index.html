What are semantic tags?

Semantic tags are HTML tags that have a clear meaning.

They tell:

  • the browser
  • search engines
  • screen readers

what the content is, not just how it looks.

Semantic tags (meaningful)

These explain the purpose of content:

  • header - top part of page
  • nav - navigation menu
  • main - main content
  • section - section of content
  • article - independent content
  • aside - sidebar
  • footer - bottom of page
